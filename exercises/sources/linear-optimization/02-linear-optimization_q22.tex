Consider a linear optimization problem. Which of the following statements is false?

\begin{itemize}
\item[(a)] {Several basic solutions may correspond to the same vertex of the feasible region.}
\item[(b)] {For each feasible basic solution, there exists at least one feasible basic direction.}
\item[(c)] {If a feasible basic solution is non degenerate, all the associated basic directions are feasible.}
\end{itemize}
