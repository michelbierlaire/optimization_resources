
Consider the polyhedron defined as follows:
\[
    \mathcal{P} = \{x \in \R^2 \mid -x_1 + x_2 \leq 2, x_1 + x_2 \leq 4, x_1 \geq 0, x_2 \geq 0\}.
\]

Determine whether the given directions $\tilde{d} \in \R^2$  are feasible for the given feasible points $\tilde{x}$ of $\mathcal{P}$:
\begin{enumerate}
    \item $\tilde{x}_a = \begin{pmatrix*}[r] 0 \\ 2 \end{pmatrix*}$, $\tilde{d}_a = \begin{pmatrix*}[r] 1 \\ 0 \end{pmatrix*};$
    \item $\tilde{x}_b = \begin{pmatrix*}[r] 0 \\ 2 \end{pmatrix*}$, $\tilde{d}_b = \begin{pmatrix*}[r] -1 \\ 0 \end{pmatrix*};$
    \item $\tilde{x}_c = \begin{pmatrix*}[r] 2 \\ 2 \end{pmatrix*}$, $\tilde{d}_c = \begin{pmatrix*}[r] 0 \\ 2 \end{pmatrix*};$
    \item $\tilde{x}_d = \begin{pmatrix*}[r] 3 \\ 0 \end{pmatrix*}$, $\tilde{d}_d = \begin{pmatrix*}[r] 0 \\ 2 \end{pmatrix*}.$
\end{enumerate}

Hints:
\begin{enumerate}
 \item If the polyhedron is written in standard form, a direction $d$ is feasible if the
    following conditions are verified:
    \begin{itemize}
         \item  $Ad = 0$, and
         \item  $d_i \geq 0$ when $x_i = 0$.
         \end{itemize}
 \item To obtain a vector $x$ in standard form, you must calculate the values of the slack variables.
 \item To obtain a \emph{direction} $d$ in standard form, you need to consider $y = x + d$. If $x^s$ and $y^s$ are
     the corresponding vectors in standard form (including the slack variables), the direction in standard form is
     $$d^s = y^s - x^s.$$
 \end{enumerate}
