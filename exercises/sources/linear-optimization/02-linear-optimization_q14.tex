Consider the polyhedron
\[
P = \left\{
\begin{pmatrix}
x_1\\
x_2
\end{pmatrix} \in \R^2
| x_1+x_2 \leq 1,
-x_1+2x_2 \leq 2, x_1 \geq 0, x_2 \geq 0 \right\}.
\]
\begin{enumerate}
\item Represent it graphically.
\item Identify the corresponding polyhedron in standard form.
\item Enumerate the feasible basic solutions, and identify the
  corresponding vertex on the polyhedron.
\item For each feasible basic solution, mention if it is degenerate or
  not.  Remember that a feasible basic solution is degenerate if at
  least one of the basic variables is zero.
\end{enumerate}
