Consider the following set of constraints:
\begin{align*}
x_1+x_2 & \geq 1,\\
x_1+x_2 & \leq 2,\\
x_1 & \geq 0,\\
x_2 & \geq 0.
\end{align*}

\begin{enumerate}
\item Draw the polyhedron in $\R^2$.
\item Write the polyhedron in standard form.
\item Enumerate all potential bases. For each of them, check if it is
  a valid basis. If so, if it is feasible. If so, identify the
  corresponding vertex on the polyhedron.
\end{enumerate}
