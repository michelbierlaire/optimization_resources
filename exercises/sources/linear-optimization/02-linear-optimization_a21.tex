{\bf Answer: (c).} 

Answer (a) is false. If all reduced costs are negative, it means that
all basic directions are decreasing. It is not possible at a minimum
of the problem in the general case. The only instance where it may happen is
when all basic directions are infeasible. Refer to the video on
\href{https://www.youtube.com/watch?v=UJEnS4brKyI}{\textit{optimality
    conditions}} for more details.
Answer (b) is false because if the
values of the basic variables are negative, then the solution is
infeasible, since the non negativity constraints are not respected. It
cannot therefore be optimal.  Answer (c) is correct. Indeed, the
reduced costs of the basic variables are zero, so that all reduced
costs are non negative (sufficient optimality conditions).
